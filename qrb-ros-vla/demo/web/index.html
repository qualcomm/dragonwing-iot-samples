1 · VLA lane Pi0.5 · NPU

Your text goes verbatim to /qrb_ros_vla/task. The model replans every chunk against the live camera frames. green chips are this world's demonstrated instruction; amber chips are its objects in wording the policy was never shown.

2 · A/B language probe proof, not vibes

Freezes one observation and asks for three chunks: prompt A, prompt B, then A again. The third is the repeat-noise floor. If A-vs-B clears that floor, the wording changed the plan — measured, on stage, in units of the dataset's action std. Takes about 3.5 s. It probes from the scene's start pose by default, because the answer depends on the pose: with the gripper already closing on an object the plan is decided and both prompts agree. Untick to probe wherever the arm currently is.

3 · Scripted lane no model in the loop

Hand-written open-loop trajectories in the same 7-DoF action space (demo/scripted_gestures.py). These are here because the VLA cannot do them: non-manipulation prompts measure indistinguishable from each other, so a "wave" driven by the policy would be theatre. This lane is honest about being choreography.
